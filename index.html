🚀 How to Host this Website for Free on GitHub Pages

Step 1: Open Your Repository Settings

Go to your repository on GitHub: https://github.com/aditya-Pratap15/BG-separator- and click on the Settings tab at the top.

Step 2: Enable GitHub Pages

In the left sidebar, click on Pages (under Code and automation).

Step 3: Select the Build Source

Under Build and deployment > Source, select:
👉 GitHub Actions (Recommended — automatically builds and deploys every push)
or Deploy from a branch > Branch: main / root.

In 1–2 minutes, your website will be live at:
